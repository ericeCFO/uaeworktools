Report a calculation issue

To report a formula, source, typo, or outdated-rule concern, contact the site operator through the channel where you received this link and include the details below.

What to include

Page URL, the calculator input pattern, the result that looked wrong, and a link to an official source if available.

What not to include

Do not send Emirates ID, passport details, employer documents, personal salary slips, or private dispute files.

Review path

Reported calculation issues are reviewed against the published methodology and official source links before changes are made.
