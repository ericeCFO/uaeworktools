Quality control

Report a calculation issue

This page should become the public feedback path for formula, source, typo, and outdated-rule reports.

What to include

Calculator name, the assumption that looks wrong, and a link to an official source if available.

What not to include

Do not send Emirates ID, passport details, employer documents, personal salary slips, or private dispute files.

Internal workflow

Reported issues should trigger a rule review before any calculator is updated.
